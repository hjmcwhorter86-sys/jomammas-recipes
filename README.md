# jomammas-recipes

A clean, ad-free recipe site built by Heather Jo (JoMamma) — designed to feel like a simple cookbook page or recipe card, without the clutter.

## Features

- Browse recipes by category
- Search across all recipes
- Calorie and protein estimates on most recipes
- Mobile-friendly layout

## Running locally

Open `index.html` in a browser — no build step needed.
